# Production metadata policy

Metadata is generated by the Astro build from one shared layout and is enabled
only when `SITE_ENV=production`. Staging emits neither canonical nor hreflang
links and remains protected by HTML robots metadata plus the public
`X-Robots-Tag` header.

## Canonicals

Every indexable production page declares one self-canonical under
`https://custody.consulting`. Canonical paths are site-relative in source; the
metadata helper rejects absolute or external inputs. Noindex pages, including
the 404 page and all draft previews, do not declare canonicals.

Paginated indexes canonicalize to their own page. Topic pages canonicalize to
their own locale-specific topic URL rather than to the parent blog index.

## Language alternates

The English and Polish homepages and blog indexes form reciprocal hreflang
pairs. A paginated blog index links only to the same page number in the other
language. Localized topic names have no explicit translation mapping, so topic
pages intentionally do not emit hreflang links.

An article emits reciprocal `en` and `pl` links only when its translated entry
is present in the production query. Because the production query excludes
drafts and the editorial boundary check requires paired draft states, an
unpublished translation cannot be advertised to crawlers.

## x-default

The neutral root language chooser is the deliberate `x-default` target for the
root pages and bilingual blog indexes. Article and topic pages omit x-default:
there is no language-neutral equivalent article or topic URL, and pointing them
to a generic page would misrepresent equivalence.

## Verification

`npm run check:metadata-output` inspects both static artifacts. It verifies:

- staging HTML contains no canonical or hreflang links and remains noindex;
- each indexable production page has a unique title and description;
- every canonical is a self-canonical on the production origin;
- alternate URLs use the production origin and translated links are reciprocal;
- every x-default link targets the neutral root chooser;
- noindex production pages declare no canonical.

Production sitemap, robots discovery and bilingual RSS rules are documented in
[`docs/SYNDICATION.md`](SYNDICATION.md). Those outputs are generated only for
the production build and have a separate artifact-level regression check.
